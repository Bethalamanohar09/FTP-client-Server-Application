CN Lab Study Guide: File Transfer Protocol (RFC 959)

1. Why does FTP use two separate connections (Out-of-band control)?

Unlike HTTP, FTP uses two distinct parallel TCP connections:

  • Control Connection (Port 21): Remains open for the entire duration of the user's session. It handles user authentication, directory navigation, file deletion, and transfer commands. Because control commands are sent over a separate stream, control is described as "Out-of-band".
  • Data Connection (Port 20 or Dynamic Ephemeral Port): Created dynamically on-demand only when actual data (a directory listing or a file content stream) needs to be transferred, and terminated immediately after the transfer finishes.

2. Active Mode (PORT) vs. Passive Mode (PASV)

Feature Active Mode (PORT) Passive Mode (PASV)
Command Used PORT h1,h2,h3,h4,p1,p2 PASV (Server replies with IP & Port)
Who opens Data Connection? Server connects back to client's specified data port Client connects to server's specified ephemeral port
Firewall / NAT Issue Often blocked because incoming connections from server to client are dropped by client firewalls Firewall-friendly! Client initiates both connections outward.

3. Core FTP Commands Reference

Control Commands:
USER <name> - Identify user
PASS <password> - Send password
PWD - Print working directory
CWD <dir> - Change working directory
CDUP - Change to parent directory
QUIT - Terminate session
Transfer Commands:
LIST - Directory contents (via Data connection)
RETR <file> - Download file (Retrieve)
STOR <file> - Upload file (Store)
DELE <file> - Delete file
MKD <dir> - Make directory
TYPE I / A - Binary (Image) or ASCII mode

4. RFC 959 Three-Digit Reply Codes Breakdown

  • 1xx (Positive Preliminary): Action started, awaiting completion (e.g., 150 Opening data connection).
  • 2xx (Positive Completion): Action successfully completed (e.g., 200 OK, 220 Ready, 226 Transfer complete, 230 Logged in).
  • 3xx (Positive Intermediate): Command accepted, but further info required (e.g., 331 Password required).
  • 4xx (Transient Negative): Temporary failure, try again (e.g., 425 Can't open data connection).
  • 5xx (Permanent Negative): Fatal error / command rejected (e.g., 500 Syntax error, 530 Not logged in, 550 File not found).

5. Common Viva-Voce Questions

Q: Can we run FTP on a single port?

A: RFC 959 specifies separation of control and data. While modern protocols like SFTP (SSH File Transfer Protocol) run over a single port (Port 22), traditional FTP strictly requires separate control and data channels.

Q: What is the difference between ASCII and Binary (Image) mode?

A: In ASCII mode, newline characters (CR/LF) are translated between different operating systems (Windows vs Unix). In Binary (Image / TYPE I) mode, bytes are transferred exactly verbatim without modification, essential for images, executables, and compressed files.
